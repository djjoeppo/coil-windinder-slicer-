## 2025-02-14 - Independent Flange Configuration and Universal CAD Emojis
**Learning:** Physical winding machine operators frequently build spools with custom geometric constraints (such as unequal left/right flange diameters, single-flange spools, or completely flangeless tubes). Hardcoding a single symmetrical flange parameter forces unnatural workarounds. Offering independent left/right flange controls that dynamically hide the associated inputs when disabled creates an extremely intuitive CAD-style mental model. Furthermore, using universal, unique pictograms (emojis) on primary buttons enables fast visual scanning and action identification without needing to parse translated text labels, breaking down linguistic barriers.
**Action:** When designing hardware or CAD-related parametric UIs, always structure physical components (like spool flanges, chucks, or fixtures) to be independently toggleable and dimensionable. Accompany critical control buttons with a single, unique, consistent visual pictogram that remains uniform across all localized translations.
